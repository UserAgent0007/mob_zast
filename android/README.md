# Лабораторна 5. Конвертер валют (Kotlin)

Нативний Android-додаток на Kotlin і Jetpack Compose. Це перепис попереднього конвертера валют: ті самі розділи, мережевий курс і збереження історії, але без React Native.

Курси беруться з `https://open.er-api.com/v6/latest/USD`. Ключ API не потрібен. Будь-яка пара рахується як `сума * rates[to] / rates[from]`.

## Як відкрити в Android Studio

1. Встанови [Android Studio](https://developer.android.com/studio) (актуальна стабільна версія). Під час встановлення залиш Android SDK і Android Virtual Device.
2. Запусти Android Studio.
3. **File → Open** і вибери саме цю папку `android`, а не всю `lab5`. У `lab5` ще лежить старий проєкт на React Native, Android Studio його не збирає.
4. Дочекайся **Gradle Sync**. Перший раз студія завантажує Gradle і бібліотеки, потрібен інтернет.
5. Якщо синхронізація свариться на JDK, відкрий **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK** і обери **Embedded JDK** (jbr-17 або jbr-21). Системну Java 24 для цього проєкту не використовуй.
6. Відкрий **Device Manager** (іконка телефону справа) → **Create Virtual Device** → Pixel → системний образ **API 35** (підійде і API 34) → Finish.
7. У списку пристроїв зверху обери цей емулятор і натисни **Run** (зелений трикутник).
8. Зачекай, поки додаток встановиться. На вкладці «Конвертер» курси підтягнуться самі.

### Запуск на телефоні

1. На телефоні увімкни параметри розробника і **Налагодження USB**.
2. Підключи телефон кабелем і дозволь налагодження.
3. У списку пристроїв Android Studio обери телефон і натисни **Run**.

Телефону й емулятору потрібен інтернет: без нього з’явиться повідомлення про відсутність з’єднання, а кнопка «Спробувати ще раз» або «Оновити курси зараз» повторить запит.

## Якщо студія не збирає проєкт через шлях

Папка лабораторної містить українські літери. У `gradle.properties` уже стоїть `android.overridePathCheck=true`. Якщо збірка все одно падає через шлях, скопіюй папку `android` у каталог лише з латинськими літерами, наприклад `D:\lab5-currency`, і відкрий уже її.

## Що є в додатку

- **Конвертер** — сума, швидкі значення, вибір пари, обмін місцями, популярні пари, збереження в історію.
- **Курси** — таблиця відносно базової валюти, пошук, обране, оновлення свайпом вниз, екран деталей пари.
- **Історія** — збережені конвертації, видалення, очищення, повернення пари в конвертер.
- **Налаштування** — знаки після коми (2 / 4 / 6), базова валюта, обране, ручне оновлення курсів.

Налаштування, остання пара й історія зберігаються на пристрої.
