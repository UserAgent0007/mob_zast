# Лабораторна 5. Конвертер валют

Нативна версія додатка для Android Studio лежить у папці [`android`](android).

Відкривай у Android Studio саме папку `android` (File → Open), не корінь `lab5`. Покрокова інструкція: [android/README.md](android/README.md).

Попередній варіант на React Native (Expo) залишився в корені цієї папки. Для цієї лабораторної його запускати не потрібно.
