# Лабораторна 4. Конвертер валют

Саморобний мобільний додаток на Flutter. Курси підтягуються з мережі, стан тримає Provider, навігація складається з нижніх вкладок і стека.

## Що реалізовано

- Конвертер: сума, швидкі суми, вибір пари, обмін місцями, популярні пари, збереження в історію.
- Таблиця курсів з пошуком, обраним і оновленням свайпом.
- Історія конвертацій: відкрити пару знову, видалити запис, очистити все.
- Налаштування: точність, базова валюта, обране, ручне оновлення.
- Окремі екрани вибору валюти та деталей пари.
- Мережевий виклик `GET https://open.er-api.com/v6/latest/USD`. Ключ API не потрібен.

Крос-курс рахується як `сума * rates[to] / rates[from]`, бо API віддає курси відносно долара.

## Структура

```
lib/main.dart                  # Provider і старт застосунку
lib/api/rates_api.dart         # мережевий виклик
lib/state/                     # курси, конвертер, історія, налаштування, вкладки
lib/navigation/routes.dart     # стек: вибір валюти та деталі
lib/screens/                   # екрани
lib/widgets/                   # власні UI-блоки
lib/data/currencies.dart       # назви та символи
lib/utils/format.dart          # конвертація та формат чисел
```

## Як запустити

Потрібен [Flutter SDK](https://docs.flutter.dev/get-started/install/windows) у `PATH`. У терміналі з цієї папки:

```bash
flutter pub get
flutter run -d windows
```

Інші варіанти:

- `flutter run -d chrome` — у браузері;
- `flutter run -d android` — на емуляторі або телефоні з увімкненим USB-налагодженням.

Папки `android`, `windows` і `web` уже згенеровані. `flutter create` повторно запускати не потрібно.

Перевірка логіки без емулятора:

```bash
flutter test
```
