# Lab 3. Конвертер валют

Саморобний мобільний додаток на JavaScript і React Native (Expo). Курси підтягуються з мережі, стан тримає Redux, навігація складається зі стека та вкладок.

## Що реалізовано

| Вимога | Як закрито |
| --- | --- |
| React Native з нуля | Expo SDK 57, власна структура `src/` |
| Redux | `@reduxjs/toolkit` + `react-redux`: курси, конвертер, історія, налаштування |
| Мережевий виклик | `GET https://open.er-api.com/v6/latest/USD` |
| Stack navigator | Кореневий стек: вкладки, вибір валюти, деталі курсу |
| Tab navigator | Конвертер, Курси, Історія, Налаштування |
| Власні інтерфейси | Кастомні картки, чіпи, кнопки валют, темна тема |

## Робочий процес розробки

1. **Ідея та екрани.** Спочатку фіксуємо користувацькі сценарії: конвертація, таблиця курсів, історія, вибір валюти.
2. **Каркас Expo.** Створюємо проєкт, підключаємо навігацію та Redux, не змішуючи UI з мережею.
3. **API окремим шаром.** Усі запити живуть у `src/api`. Слайс лише викликає thunk.
4. **Стан у Redux.** Екрани не зберігають курси локально: вони читають store і відправляють actions.
5. **Навігація шарами.** Вкладки — основні розділи. Стек відкриває допоміжні екрани зверху.
6. **Власний UI.** Тема в `src/theme.js`, повторювані блоки винесені в `src/components`.
7. **Перевірка.** `npm start` → Expo Go на телефоні або емулятор. Оновлення курсів — pull-to-refresh і кнопка в налаштуваннях.

## Як запустити

```bash
npm install
npm start
```

Далі:

- відскануйте QR у Expo Go;
- або натисніть `a` для Android / `w` для web.

Ключ API не потрібен.

## Структура

```
App.js                     # Provider, перше завантаження курсів
src/api/rates.js           # мережевий виклик
src/store/                 # Redux slices
src/navigation/            # stack + tabs
src/screens/               # екрани
src/components/            # власні UI-блоки
src/data/currencies.js     # назви, прапори, символи
src/utils/format.js        # конвертація та формат чисел
```

## Логіка конвертації

API віддає курси відносно долара. Будь-яка пара рахується як

`сума * rates[to] / rates[from]`.
